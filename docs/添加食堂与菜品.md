# 如何添加新的食堂与菜品

> 适用版本：v1.0（demo1号版本，真实后端）
> 推荐方式：使用**网页管理后台**维护数据，无需改代码；下文"Mock 兜底方案"仅适用于 `USE_MOCK = true` 的演示模式。

## 数据流向概览

```
页面（Index / DishDetailPage ...）
  └─ net/Api.ets（USE_MOCK = false 时走真实后端）
      └─ server/（Express + SQLite，数据由网页管理端 / App 写入）
```

## 推荐方式：网页管理后台（无需改代码）

1. 启动后端：`cd server && npm start`（默认端口 3000）
2. 浏览器打开 `http://localhost:3000`，使用管理员账号登录（默认 `admin / admin123`）
3. 在 **食堂 / 档口 / 菜品** Tab 中完成增删改：
   - 新增/编辑食堂（名称、位置、营业时间、楼层数）
   - 新增/编辑档口（归属食堂、名称、楼层）
   - 新增/编辑菜品（归属档口、名称、价格、标签、图片上传、售罄开关）
   - 评价审核 Tab 中可下架违规评价
4. 保存后 App 端刷新即可看到新数据（食堂菜单 / 菜品搜索均实时读取数据库）

> 删除食堂/档口会级联删除其下档口/菜品，操作前有确认提示。售罄开关即时生效，App 端卡片将置灰并提示。

---

## Mock 兜底方案（USE_MOCK = true 时）

> 相关文件：`entry/src/main/ets/data/MockData.ets`、`entry/src/main/ets/model/Canteen.ets`、`entry/src/main/ets/model/Dish.ets`

添加食堂/菜品 = 修改 `MockData.ets` 中的静态数据，改完重新运行即可生效，无需改页面代码。

---

## 一、添加食堂

打开 `MockData.ets`，在 `private static canteens` 数组末尾追加一行（约第 18 行）：

```typescript
private static canteens: Canteen[] = [
  new Canteen('c1', '第一食堂', '校园东区', '06:30-21:00', 3, ''),
  new Canteen('c2', '第二食堂', '校园西区', '06:30-21:00', 2, ''),
  new Canteen('c3', '清真食堂', '校园北区', '06:30-20:00', 1, ''),
  new Canteen('c4', '第三食堂', '校园南区', '06:30-21:00', 2, '')   // ← 新增
];
```

**构造函数参数顺序**：`id, name, location, openHours, floors, image`

| 参数 | 类型 | 说明 |
|---|---|---|
| id | string | **全局唯一**，如 `'c4'`（不可与已有食堂重复） |
| name | string | 食堂名称，会显示在食堂 Tab 与档口筛选标题（`📍 xx食堂 档口`） |
| location | string | 位置描述，如"校园南区" |
| openHours | string | 营业时间展示文本 |
| floors | number | 楼层数 |
| image | string | 封面图文件名（留空即可，与现有食堂一致） |

> 注意：`getStallList(canteenId)` 目前对**所有食堂返回同一组档口**（川菜/面食/盖浇饭）。如需为不同食堂配置不同档口，需改写该方法按 `canteenId` 分支返回。

## 二、添加菜品

分两步：**① 准备图片 → ② 在 `buildDishes()` 中注册菜品**。

### 第 1 步：准备图片（可选）

- 将图片文件放入 `entry/src/main/resources/rawfile/` 目录，命名为 `dish_N.png`（如 `dish_7.png`）
- 菜品 `image` 字段填**文件名**（如 `'dish_7.png'`），页面通过 `CommonUtil.dishImageSource()` 解析为 `$rawfile()` 资源
- 没有新图片时可直接复用已有图（如 `'dish_1.png'`）

### 第 2 步：在 `buildDishes()` 中注册菜品

在 `MockData.ets` 的 `buildDishes()` 方法内（约第 90 行 `list.push(d6);` 之前/之后）追加代码块：

```typescript
const d7 = new Dish();
d7.id = 'd7'; d7.stallId = 's1'; d7.canteenId = 'c4'; d7.name = '鱼香肉丝';
d7.price = 13.5; d7.tags = ['招牌', '荤'];
d7.stallName = '川菜窗口'; d7.canteenName = '第三食堂'; d7.floor = 1;
d7.rating = 4.4; d7.reviewCount = 36; d7.isSignature = true; d7.soldOut = false;
d7.nutrition = new Nutrition(540, false, []);
d7.image = 'dish_1.png';   // 或 'dish_7.png'（放入 rawfile 后）
list.push(d7);
```

**Dish 字段说明（必填项加 ★）**

| 字段 | 类型 | 说明 |
|---|---|---|
| id ★ | string | **全局唯一**，如 `'d7'` |
| stallId ★ | string | 所属档口 id，需与 `getStallList()` 返回的档口一致（现有 `'s1'/'s2'/'s3'`） |
| canteenId ★ | string | 所属食堂 id，决定显示在哪个食堂 Tab 下 |
| name ★ | string | 菜品名，用于展示与搜索 |
| price ★ | number | 价格（元） |
| image ★ | string | rawfile 图片文件名 |
| stallName ★ | string | 档口名称（与 stallId 对应，卡片上展示用） |
| canteenName ★ | string | 食堂名称（与 canteenId 对应） |
| tags | string[] | 标签，如 `['招牌','辣','荤']`；辣/荤走暖色标签样式 |
| floor | number | 所在楼层 |
| rating | number | 展示评分（0~5） |
| reviewCount | number | 展示评价数（仅展示值，真实评价见下方"配评价"） |
| isSignature | boolean | 是否招牌菜（详情页金标） |
| soldOut | boolean | 是否售罄（true 时卡片置灰、点击提示不可进详情） |
| nutrition | Nutrition | `new Nutrition(卡路里, 是否素食, 过敏原数组)` |

---

## 三、让新菜品出现在正确位置

- **食堂归属**：由 `canteenId` 决定（首页 `getTodayMenu(canteenId, ...)` 按它过滤）
- **早餐显示限制**：`getTodayMenu` 对 `MealType.BREAKFAST` 只返回该食堂菜品列表的**前 2 个**。想让新菜品在早餐 Tab 出现，需把它排在该食堂菜品的前 2 位（或调大 `slice(0, 2)` 的数字）
- **午餐/晚餐**：显示该食堂全部菜品

## 四、给新菜品配置评价（可选）

`MockData.ets` 的 `buildReviews()` 方法内追加 `Review`，并把 `dishId` 指向新菜品 id：

```typescript
const r19 = new Review();
r19.id = 'r19'; r19.dishId = 'd7'; r19.userId = 'u1'; r19.userNickname = '小张';
r19.rating = 5; r19.dimensions = new ReviewDimensions(5, 4, 5);
r19.content = '下饭神器，酸甜可口！';
r19.likes = 8; r19.isAnonymous = false; r19.status = ReviewStatus.APPROVED;
r19.createTime = '2026-09-24T12:00:00';
list.push(r19);
```

> 评价分页每页 8 条（`AppConfig.REVIEW_PAGE_SIZE`）。若想完整测试"加载更多"，评价条数应 ≥ 8。

## 五、常见问题排查

| 现象 | 原因与解决 |
|---|---|
| 首页看不到新菜品 | 检查 `canteenId` 是否与当前选中食堂一致；早餐 Tab 只显示前 2 个 |
| 图片不显示 | 确认文件放到了 `rawfile/` 且 `image` 字段填的是**文件名**（不是路径） |
| 新菜品没有标签样式 | `tags` 为空或标签词不在 `['辣','荤']` 暖色集合内，会走默认绿色标签 |
| 点击卡片报"已售罄" | `soldOut = true` 时卡片置灰不可进详情，属正常交互 |
| 改数据后界面无变化 | 页面已缓存（MockData 静态字段导航时可能重新求值），重新编译/运行即可 |
